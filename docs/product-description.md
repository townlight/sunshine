# Townlight Records — product description

Townlight Records supports municipal records work through request tracking,
document ingestion/search, staff-assisted review and audit history. Staff retain
responsibility for disclosure decisions and the actual response. See the
[operating manual](../USER-MANUAL.md) for implemented workflows and limits.

Version 1.8.0.dev2 is included in [Windows MSI 1.7.0.1](https://github.com/townlight/townlight/releases/tag/townlight-beta-1-windows-1.7.0.1). The native suite and standalone Compose deployment have separate
installation and operating boundaries. Package checks are not installer acceptance.

The [original product-team draft](history/pre-naming-2026-11/docs/product-description.md)
is preserved with its original identities and aspirational statements. Its timing,
cost and outcome claims are not current verified product claims.
