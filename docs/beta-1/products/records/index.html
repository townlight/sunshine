Inside the workflow

What Records supports

Keep the case together

Track clarification, deadlines, fees and correspondence in the request history.

Work from the source

Use cited search and linked documents to assemble a response that another officer can review.

Control what leaves

Keep private attachments separate from approved release files and verify the exported package.

Evaluate locally

Start with one real workflow.

In Townlight for Windows, enable Records and configure named staff roles. Begin with a synthetic request, a local document, and a response approval.
